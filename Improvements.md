## 13. Canonical, sitemap и robots.txt

Проверь все технические файлы индексации.

### Canonical

- У каждой индексируемой страницы корректный canonical.
- Нет случайного canonical на главную.
- Нет конфликтов между canonical и hreflang.
- Нет ссылок на тестовые домены.
- Учитывается фактический production URL.

### Sitemap

- Содержит только существующие индексируемые URL.
- Не содержит localhost.
- Не содержит несуществующих страниц.
- Не содержит случайных дубликатов.
- Соответствует текущей структуре языков и маршрутов.

### Robots.txt

- Не блокирует сайт случайно.
- Не содержит неправильных ссылок.
- Указывает sitemap при необходимости.
- Не включает локальные или тестовые адреса.

Не исключай важные коммерческие страницы из индекса без причины.
