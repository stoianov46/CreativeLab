1. **Truth Rule.** Never invent clients, testimonials, ratings, awards, certificates, results, statistics, years of experience, team size or confirmed prices. Concept projects must stay labelled as concepts. Prices stay "indicative". Never promise rankings, leads or sales.
2. **No git commit unless the user asks in that turn. No push, no deploy, no DNS change** without explicit approval.
3. **Never send a real inquiry or a real Telegram message.** Use the mocks (`npm run contact:check`).
4. **Never put secrets in the code** or in `NEXT_PUBLIC_*` variables. See `SECURITY.md`.
5. **English first.** Edit the English TypeScript file, then update RU/TH/HE JSON, then run `npm run i18n:check` (it must show 0 pending). Run `npm run i18n:accept` only when the pending keys are exactly the keys you translated.
6. **Prices:** change numbers only in `src/content/pricing.ts`. Then run `npm run pricing:master`. Never type a price into page text.
7. **If you change setup** (config files, scripts, env variables): update `README.md`, `docs/Index.md` and `.env.example` in the same change.
8. **Unfinished work** goes into section 4 of THIS file (add a line with the group A–G). Do not create new TODO or NOTES files.
9. Never use a CDN or third-party script in the site. Never change the user's system or browser settings.
