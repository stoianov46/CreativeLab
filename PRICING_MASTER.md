# Pricing Master

Single source of truth: [`src/content/pricing.ts`](src/content/pricing.ts). A pricing row in
`src/content/**` references an id (`priceId`); the figure, unit, revisions and turnaround are
rendered from that file in every language. Locale JSON files hold only translated wording
(service name, note, included / not included lists), never figures.

Status: **INDICATIVE — not confirmed commercial offers.** Pricing last reviewed: **2026-11-03**.
Structured data must not present these as confirmed offers. Method and sources: [PRICING_STRATEGY.md](PRICING_STRATEGY.md) (Advertising researched so far; evidence is thin).

Check: `npm run pricing:check` (also runs in CI). Regenerate the table below after editing
`pricing.ts`: `npm run pricing:master`.

## Draft values awaiting owner approval

The **revisions** and **turnaround (working days)** columns, for every row that has them, are **drafts set by service type** (photo 1 revision / 7–10 days, video 2 / 7–21, design 2–3 / 5–45, websites 2 / 10–60, audits 5–7 days). They are shown publicly in the table, so the owner must approve or change them before launch. Only the Advertising figures were checked against any market evidence (thin).

## Rules

- Add or change a price only in `pricing.ts`, then bump `PRICING_UPDATED` and run `npm run pricing:master`.
- All figures render in `en-US` grouping in every language (`THB 15,000 – 35,000`), so they are character-identical.
- Numbers that appear inside translated text (e.g. "5 assets") must match English; `pricing:check` fails otherwise.
- `custom` and `bundled` prices show a translated label instead of a figure.
